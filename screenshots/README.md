# Application screenshots

Capture screenshots after launching `python app.py` on a desktop with Tkinter.
Suggested views:

1. `playlist-structure-lab.png` — node cards showing HEAD, TAIL, CURRENT, and links.
2. `playlist-insert-trace.png` — inserted node and pointer trace explanation.
3. `playlist-reverse-shuffle.png` — compare order after reverse and shuffle.
4. `playlist-save-load.png` — playlist restored from a JSON file.

On Windows use **Win+Shift+S**; on macOS use **Shift+Command+4**; on Linux use
the desktop screenshot utility. Save captured images in this folder. The
repository intentionally does not include fabricated application screenshots.
